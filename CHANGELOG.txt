AURORADIGITALCARD - CHANGELOG
Versioning scheme: v#.#.#-[stage] (semver)
Patch = fixes | Minor = new content (patch resets) | Major 0 until launch (v1.0.0)
Stages: -alpha → -beta at feature-complete → -rc1 when launch-ready → v1.0.0 gold
Deployed web repo: the version lives in <meta name="version"> in index.html and here,
not on the root folder name (renaming the root would break Firebase/Actions paths).
Archived (outgoing-version) copies live in _version_archive/, never in the working tree.
